- **写真は端末の匿名キーに紐づくだけで、公開も共有もしない**。API はキーが一致する行にしか読み書きさせない。限界は他の匿名キーと同じ（認証ではない）。画面にその旨を小さく書く
- **写真が付く行は、その温泉地を最初に取得した行**（同じ温泉地を別の日に取っても写真が動かないように）
- **デモ用の初期写真**は `public/memories/<code>/*.jpg`（最大2枚）。アップロードと同じ API 経由で縮小・EXIF除去して配信するので、元ファイルの EXIF は外に出ない。アップロードの2枚上限に数える。削除はできない（ファイルを消す）。**代表者本人の写真**（README に明記）。個人の写真なので、git に入れるかは本人が決める
- **`npm run demo-seed [user_key]` / `npm run demo-reset`**：撮影用。`goyuin` の取得記録（と `data/photos` の写真）を消し、キャラ画像のある6温泉地を所持にする。キーを省くと、記録の最後の行のキー。杖立は今日・雪見・今日の湯つき。**実データを消すので撮影用の端末・DB でだけ使う**
