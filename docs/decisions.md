## 2026-11-06 「湯の個性」説明文を Agent SDK で生成する（src/agents/）

御湯印の詳細画面（/goyuin/[code]）に、その湯の泉質を温泉に詳しくない人向けに200字で言い換えた説明文を出す。ダッシュボード・湯日誌・検知・eval・スキーマの `maintenance_event` などの松井さん担当のファイルには触らない。

- **入力**：杖立（43）は `data/maruso_analysis_2014.json`（泉質名・泉温・蒸発残留物・主要成分の上位3）、他46件は `data/onsen_master_47.csv` の代表泉質だけ。ほかの情報（観光協会の紹介文、5か所の一言など）は渡さない
- **3段構成**（`@anthropic-ai/claude-agent-sdk` の `query()`。各段は道具なし・設定ファイルなし・1ターン）
  - ① **writer**（Sonnet 5.5）：200字（180〜220字）で言い換える。渡した事実だけを使い、数値は渡した数値だけ
  - ② **safety-checker**（Haiku 5.5 ＋ コードの検査）：コードで「効く・治る・安全・保証・必ず・安心」など医療・安全保証の表現（`FORBIDDEN_TERMS` ＋ 追加語）、渡していない数値、文字数を決まった手順で検査し、Haiku が言い回しの意味（効能をほのめかす、断定、数値の言い換え）を見る。1つでも見つかれば、指摘を添えて writer に差し戻す（最大3回書き直し）。直らなければ保存しない
  - ③ **citer**：出典を末尾に付ける。**LLM にはせず、コードで付ける**。分析書番号や日付を LLM が書き間違えるのを避けるため（杖立：「温泉分析書 第K13108663号（分析日 2014-02-25）。読み取りは原本未照合」、他：「代表泉質のみ・要確認」）。本文と出典は別の列に保存する
- **数値の扱い（CLAUDE.md 絶対ルール2）**：渡した事実に出てくる数値だけを許し、それ以外の数値が本文に出たら差し戻す。杖立の **pH は分析書に要確認の印があるので渡さない**（分類名の「弱酸性」も pH と食い違うため渡さない）。他46件には数値の出典がないので、代表泉質の文字列に含まれる数字だけ
- **キャッシュ**：新しい表 `onsen_personality`（code・本文・出典・種別・モデル・書き直しの回数・実行ログ）。画面は DB を読むだけで、**画面を開いても API は呼ばない**。生成は `npm run personality`（`-- --code 43`、`-- --all`、`-- --force`）。生成済みは再実行しても飛ばす
- **表示**：未所持の温泉地には出さない（既存のマスクと同じ）。「AI（Claude）が書いた説明です」と添える。生成前は何も出さない
- **実行ログ**：差し戻しが起きた例を docs/devlog.md に残す。DB の `log` 列にも各回の下書き・指摘を保存する
